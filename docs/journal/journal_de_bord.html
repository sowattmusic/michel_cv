01La demande

Créer un site web pour Michel Gallone à partir de son CV et de quatre sources en ligne :

  • LinkedIn : linkedin.com/in/michelgallone
  • Headliner Magazine USA n° 23, pages 62 à 64 (Issuu)
  • Sa page de liens : linkin.bio/mg
  • Ses crédits Discogs : discogs.com/artist/323111-Michel-Gallone

Le site doit être une vitrine de type boutique qui « vend » Michel sur le marché du travail. Il est rédigé entièrement en français, et une version anglaise sera faite ensuite. Chaque étape est documentée dans ce PDF, conservé dans l'environnement de travail et dans le dépôt GitHub.

Pour que le site « vende » Michel, ses compétences sont présentées comme une vitrine de domaines d'expertise. Le visiteur les filtre et, d'un clic sur « En discuter », écrit directement à Michel au sujet du domaine choisi. (La première version comportait un panier, retiré ensuite : voir l'étape 12.)

07Développement

Site statique, sans outil de construction : il s'ouvre directement dans un navigateur et s'héberge n'importe où (GitHub Pages, Infomaniak…).

site/
├── index.html            redirige vers fr/
├── fr/index.html         la page en français
├── en/                   (à venir) la version anglaise
└── assets/
    ├── css/style.css     styles, responsive, palette
    ├── js/main.js        menu, filtres, liens « En discuter », animations
    └── img/              photos optimisées

Fonctionnement des boutons « En discuter »

  • Chaque domaine a un bouton « En discuter » qui ouvre la messagerie du visiteur avec un e-mail prérempli vers michel@sowattmusic.com : objet « Prise de contact · nom du domaine », et un début de message.
  • Sans JavaScript, le bouton renvoie simplement à la section Contact.
  • Aucun serveur ni formulaire tiers n'est nécessaire.
  • La sélection est gardée dans le navigateur du visiteur s'il revient plus tard. Si ce stockage est bloqué, le site fonctionne quand même.

Préparé pour la version anglaise

  • Les textes générés par le script sont regroupés par langue (fr et en) dans main.js ; les textes anglais sont déjà prêts.
  • Le sélecteur FR / EN est en place ; EN est grisé « bientôt ».
  • La balise hreflang anglaise est prête, en commentaire.

Référencement

Titre et description de page, balises Open Graph pour le partage sur les réseaux, et données structurées schema.org « Person » (métier, adresse, liens LinkedIn, Instagram, Facebook, Discogs).
